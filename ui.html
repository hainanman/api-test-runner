判定规则：默认看状态码是不是 2xx；如果请求名里写了 → 404 这种，就按 404 判定（用于"预期失败"的用例）。
数据重置：本地演示接口每次运行前会自动恢复初始数据，所以同一个集合反复跑结果一致（你自己的接口不会被碰）。
每条结果下面都会写清原因，点「看服务端返回」能看到接口真实返回的内容。
注意：集合里自带的 JavaScript 断言脚本（pm.test）不会被执行，这里是通用检查。
仅支持公网可访问的接口；内网地址（192.168.x.x、localhost）本机演示可用，部署到公网后不可达。
